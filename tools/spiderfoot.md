# SpiderFoot

## 📌 Sobre

O **SpiderFoot** é uma ferramenta de OSINT que automatiza a coleta de informações sobre domínios, endereços IP, e-mails, nomes de usuário e outros alvos.

Ela utiliza diversas fontes públicas para gerar um relatório detalhado de reconhecimento.

---

## 🚀 Instalação

Clone o repositório oficial:

```bash
git clone https://github.com/smicallef/spiderfoot.git
```

Entre na pasta:

```bash
cd spiderfoot
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

---

## ▶️ Utilização

Execute a ferramenta:

```bash
python3 sf.py
```

Depois acesse no navegador:

```
http://127.0.0.1:5001
```

---

## 📖 Recursos

- Pesquisa de domínios.
- Pesquisa de IPs.
- Pesquisa de e-mails.
- Pesquisa de nomes de usuário.
- Coleta automática de informações.
- Interface web.

---
