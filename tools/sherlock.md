# Sherlock

## 📌 Descrição

O **Sherlock** é uma ferramenta de OSINT (Open Source Intelligence) utilizada para localizar nomes de usuário em centenas de redes sociais e serviços online.

## ⚙️ Instalação

```bash
git clone https://github.com/sherlock-project/sherlock.git
cd sherlock
pip3 install -r requirements.txt
```

## 🚀 Utilização

```bash
python3 sherlock.py nome_do_usuario
```

## 📖 Exemplo

```bash
python3 sherlock.py crocodande
```
