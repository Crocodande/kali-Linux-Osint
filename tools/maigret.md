# Maigret

## 📌 Sobre

O **Maigret** é uma ferramenta de OSINT desenvolvida para localizar nomes de usuário em centenas de sites e serviços online.

Ela ajuda investigadores, analistas e pesquisadores a descobrir a presença digital de um usuário em diversas plataformas.

---

## 🚀 Instalação

Clone o repositório oficial:

```bash
git clone https://github.com/soxoj/maigret.git
```

Entre na pasta:

```bash
cd maigret
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

---

## ▶️ Utilização

Pesquisar um nome de usuário:

```bash
maigret nome_do_usuario
```

---

## 📖 Exemplo

```bash
maigret crocodande
```

---

## ⚠️ Aviso

Utilize a ferramenta apenas em ambientes autorizados e para fins educacionais ou de investigação ética.
