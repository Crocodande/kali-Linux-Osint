# Maltego

## 📌 Sobre

O **Maltego** é uma plataforma de OSINT e análise de relacionamentos utilizada para investigar pessoas, organizações, domínios, endereços IP, e-mails e diversas outras entidades.

Sua interface gráfica permite visualizar conexões entre informações coletadas em diferentes fontes públicas.

---

## 🚀 Instalação

O Maltego pode ser baixado diretamente no site oficial.

Após a instalação, faça login com uma conta gratuita ou licenciada para utilizar os recursos da plataforma.

---

## ▶️ Utilização

1. Abra o Maltego.
2. Crie um novo gráfico.
3. Adicione uma entidade (domínio, e-mail, pessoa, etc.).
4. Execute os **Transforms** para coletar informações públicas.
5. Analise os relacionamentos encontrados.

---

## 📖 Recursos

- Visualização gráfica de relacionamentos.
- Investigação de domínios.
- Pesquisa de e-mails.
- Pesquisa de pessoas.
- Integração com diversas fontes OSINT.
- Interface intuitiva.

---

## ⚠️ Aviso

Utilize o Maltego apenas para fins educacionais, investigações autorizadas e atividades realizadas de forma ética e legal.
