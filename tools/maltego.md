# Maltego

## 📌 Sobre

O **Maltego** é uma plataforma de OSINT e análise de relacionamentos utilizada para investigar pessoas, organizações, domínios, endereços IP, e-mails e outras entidades.

Sua interface gráfica permite visualizar conexões entre informações coletadas de diferentes fontes públicas.

## 🚀 Instalação

O Maltego pode ser baixado diretamente pelo site oficial.

Após a instalação, faça login com uma conta gratuita ou licenciada para utilizar os recursos disponíveis.

## ▶️ Utilização

1. Abra o Maltego.
2. Crie um novo gráfico.
3. Adicione uma entidade, como domínio, e-mail ou pessoa.
4. Selecione a entidade e execute os **Transforms** disponíveis.
5. Analise as informações e os relacionamentos encontrados no gráfico.

## 📖 Recursos

- Visualização gráfica de relacionamentos.
- Investigação de domínios.
- Pesquisa de e-mails.
- Pesquisa de pessoas.
- Integração com diversas fontes OSINT.
- Interface gráfica para análise de informações.

## ⚠️ Aviso

Utilize o Maltego apenas para fins educacionais, investigações autorizadas e atividades realizadas de forma ética e legal.
