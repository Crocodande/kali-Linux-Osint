# Photon

## 📌 Sobre

O **Photon** é uma ferramenta OSINT desenvolvida para realizar reconhecimento de aplicações web.

Ela coleta informações públicas sobre um site, identificando URLs, arquivos, subdomínios, tecnologias utilizadas, palavras-chave e outros recursos que auxiliam na fase de reconhecimento de um alvo.

---

## 🚀 Instalação

### Clonar o repositório

```bash
git clone https://github.com/s0md3v/Photon.git
```

### Entrar na pasta

```bash
cd Photon
```

### Instalar as dependências

```bash
python3 -m venv ~/venvs/photon
```
```bash
source ~/venvs/photon/bin/activate
```
```bash
pip install -r requirements.txt
```
---

## ▶️ Exemplo de uso

```bash
python3 photon.py -u https://exemplo.com
```

---

## 📖 Exemplo de saída

A ferramenta poderá identificar:

- URLs encontradas.
- Arquivos e diretórios.
- Subdomínios.
- Tecnologias utilizadas pelo site.
- Palavras-chave.
- Recursos públicos disponíveis.
