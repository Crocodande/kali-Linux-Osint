# Comandos Linux

Este documento reúne comandos Linux utilizados durante o desenvolvimento do projeto Kali Linux OSINT.

## Navegação

### pwd

Mostra o diretório atual.

Exemplo: pwd

### ls

Lista os arquivos e diretórios do local atual.

Exemplo: ls


### cd

Muda para outro diretório.

Exemplo: cd ~/Projects/kali-Linux-Osint

### cat

Mostra o conteúdo de um arquivo.

Exemplo: cat README.md
