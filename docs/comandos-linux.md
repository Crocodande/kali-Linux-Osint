# Comandos Linux

Este documento reúne comandos Linux utilizados durante o desenvolvimento do projeto Kali Linux OSINT.

## Navegação

### pwd

Mostra o diretório atual.

Exemplo: pwd

### ls

Lista os arquivos e diretórios do local atual.

Exemplo: ls


### cd

Muda para outro diretório.

Exemplo: cd ~/Projects/kali-Linux-Osint

### cat

Mostra o conteúdo de um arquivo.

Exemplo: cat README.md

## Arquivos e diretórios

### mkdir

Cria um novo diretório.

Exemplo: mkdir documentos
### ls
Lista arquivos e diretórios.
Exemplo: ls

### pwd
Mostra o diretório atual.
Exemplo: pwd

### grep
Pesquisa por texto dentro de arquivos.
Exemplo: grep "Linux" README.md

### nano
Edita arquivos de texto.
Exemplo: nano README.md

### clear
Limpa o conteúdo da tela do terminal.
Exemplo: clear

### chmod
Altera as permissões de arquivos e diretórios.
Exemplo: chmod +x script.sh

### ./
Executa um arquivo ou script no diretório atual.
Exemplo: ./script.sh

### find
Localiza arquivos e diretórios.
Exemplo: find . -name "README.md"

### rm
Remove arquivos.
Exemplo: rm arquivo.txt

### cp
Copia arquivos e diretórios.
Exemplo: cp arquivo.txt backup.txt

### mv
Move ou renomeia arquivos e diretórios.
Exemplo: mv arquivo.txt novo_nome.txt

### sudo
Executa comandos com privilégios de administrador.
Exemplo: sudo apt update

### apt
Gerencia pacotes e programas no Kali Linux.
Exemplo: sudo apt install nome-do-programa

### git status
Mostra o estado atual do repositório Git.
Exemplo: git status

### git add
Prepara arquivos para serem incluídos no próximo commit.
Exemplo: git add README.md

### git commit
Registra as alterações no histórico do Git.
Exemplo: git commit -m "Mensagem do commit"

### git push
Envia os commits do repositório local para o GitHub.
Exemplo: git push origin main

### git pull
Baixa e integra alterações do GitHub no repositório local.
